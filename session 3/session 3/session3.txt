Question 4:

Identify and correct the invalid variable names from this list: 1stPlayer, player_age, $score, total-marks, userName. Apply standard variable naming rules for C programming.

Answer:

Variable naming rules in C: The name must start with a letter or underscore. It cannot start with a number or special character. It cannot contain spaces, hyphens, or symbols like $ or @. Only letters, digits, and underscores are allowed.

1. 1stPlayer INVALID Starts with a number. Corrected: firstPlayer

2. player_age VALID No changes needed.

3. $score INVALID $ symbol not allowed. Corrected: score

4. total-marks INVALID Hyphen not allowed. Corrected: total_marks
